<Callout type="warn">From `v4` of `react-native-reanimated`, you must also
install `react-native-worklets` as a peer dependency.</Callout>

Run this in your project root. It's the whole setup: there's no provider to add, font to link or
native step to run.

### React Native CLI

Expo projects include the Worklets Babel plugin already. On the React Native CLI, add
`react-native-worklets/plugin` to `babel.config.js` as the
[Reanimated setup guide](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started/)
describes.

### Upgrading from 0.4

Earlier versions linked an icon font for `Checkbox`. It now draws its tick without one, so you can
remove `"rn-neo"` from the `plugins` in `app.json`. Leaving it in is harmless.
