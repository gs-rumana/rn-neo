<Callout>After installing RN Neo, import a component and use it. There's nothing to set
up first.</Callout>

- Import the components

```tsx
import { Pressable, Text } from 'rn-neo';
```

- And use it in your app

```tsx
<Pressable backgroundColor="primary">
  <Text>Sign Up</Text>
</Pressable>
```

## Theme

Components use `DefaultLightTheme` until you wrap your app in `NeoProvider`. Add it when you want
dark mode or your own tokens:

```tsx
import { NeoProvider, DefaultDarkTheme } from 'rn-neo';

export default function App() {
  return <NeoProvider theme={DefaultDarkTheme}>{/* Your app code */}</NeoProvider>;
}
```

See [Customization](/docs/customization) for every token you can change.
